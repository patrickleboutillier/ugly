# The core (`src/`)

Notes for Claude Code, loaded when working in this directory. The project's rules are in the root `CLAUDE.md`.

**`src/`** is the core (`libugly` 2.7.0, plugin ABI 5):

- `handles.c`: the handle table. A handle is a slot index plus a generation. It also holds borrow slots, the (home, identity) index and the per-runtime queues of deferred releases, all under one lock. Plugin code never runs under that lock. Two hot paths skip it (they made every call serialize, tests/bench.c): `h_lookup` reads slots as a seqlock (slots in chunks that never move; `kind`, `gen`, `target`, `home` and `ref` are written with `PUT` inside `write_begin`/`write_end`, which bump the slot's `seq`; it falls back to the lock after 64 tries), and `h_drain` checks `npending` atomically first. Any new write to those fields must go through `PUT` inside a write section. Checked with ThreadSanitizer (`-Db_sanitize=thread`, run under `setarch x86_64 -R` on this kernel).
- `ctx.c`: one ctx per thread (`_Thread_local current`) and errors.
- `rt.c`: runtimes and frames. `rt_enter`/`rt_leave` check the thread, enforce `UGLY_MAX_DEPTH`, drain deferred releases and revoke borrows. `after_call` normalizes plugin results.
- `protocol.c`: the operations.
- `lang.c`: plugin loading through `UGLY_PLUGIN_PATH`, with `RTLD_GLOBAL` and counted loads. Also the core's fork handlers (`lang_fork_safety`, from `ugly_ctx_new`): `langs_lock`, `opts_lock` and the handle table's lock are held across a fork; `langs_take`/`langs_give` track the holder, so a fork from a plugin's `init` (under `langs_lock`) doesn't deadlock.
- `ugly.map`: the linker's version script. libugly exports only `ugly_*`; its internals (`xstrdup`, `on_thread`, `rt_enter`...) are local, so a host built with `-rdynamic` can't interpose them (test `symbols`).
- `host.c`: the built-in "c" language, which is the home of C callables and core lists and maps. Each ctx has one runtime of it.

## Rules that are easy to get wrong here

- Threads (contract §6): `UGLY_CAP_ANY_THREAD` (Python, Java) lets any thread enter; `rt_enter` counts itself in (`depth`, atomic) before checking `closing`, `rt_destroy` sets `closing` before checking `depth`. Releases to such runtimes are always queued. `ugly_rt_get` shares them (`shares`, `auto_created`, `destroyed` under the langs lock; `rt_unshare`). `ugly_ctx_thread` makes a ctx deleted at thread exit (pthread key); Python's `need_ctx` and Java's `native_ctx` use it. Python wraps calls out in `OUT()` (GIL released). Phase 2: `ugly_rt_set_host_serialized` makes one runtime any-thread on the host's promise (HAProxy's `lua-load`; Lua's `ugly.shared_by_threads()`, called when `core.thread == 0`); the Lua binding calls `ugly_rt_drain` at each entry, and so do the any-thread languages wherever their own code uses `ugly` (Python's `need_ctx`, Java's `native_ctx`, C#'s `Ops.Ctx`, Haskell's `currentCtx` when outside any entry: `ugly_hs_outside`, then the safe `ugly_hs_drain`), since their releases are always queued and a program that only calls out never enters its runtime through the core; QuickJS resets its stack top on outermost entry.
- The plugin ABI is 5: `delete_member` and `splice` (2), `options` (3), `call_opts`/`invoke_opts`/`new_opts` (4), `iter`/`next`/`to_string` (5; the core requires an exact match, so `Binding.cs`'s `PluginTable` moves with it).
- Iteration (contract §2, decisions 18 to 25): `UGLY_TRAIT_ITERABLE`, `ugly_iter` (an iterator handle; on an iterator, itself), `ugly_next(it, want, out, max, &got)` (`got < max` is the end; batches never run ahead; values before an error are kept), release closes; `ugly_to_string` (STRING or BYTES; `NOT_SUPPORTED` for C values). Exact or refused, no fallback over ELEMENTS. Done in the core (`protocol.c`; core lists' `C_ITER` in `host.c`), the mock (generators `count_to`, `naturals`, `fail_after`, `produced`; `sum_iter`, `take_iter`, `stringify`), Python (`iter()`/`next()`/`str()`; proxies have `tp_iter`, `tp_iternext`, `tp_str`, and fall back to the sequence protocol for an ELEMENTS value its language doesn't iterate; `len()` of a proxy without length is `TypeError`, so `list(p)`'s length hint skips it) and Lua (every function is ITERABLE; `ugly_iter` wraps it in an `ugly.iterator` userdata holding `{ f, control }`, stepping `f(nil, control)` as the generic for; `ugly.iter(p)` in Lua; a proxy's `tostring` is `ugly_to_string`) and Haskell (`Info`'s `infoIter`: `Iterable` makes an iterator, `Iterator` steps; a list's iterator is an MVar over its remaining cells, one forced per step; `infoShow` is `IO String`, so a counter's text is current; a foreign iterable that isn't ELEMENTS becomes a lazy list where `[a]` is wanted, a home iterable too; `Ugly.toList`/`iter`/`next`/`toString`; `BRIDGE_ABI` 7); and JS (`Symbol.iterator`; `next()` until `done`; a box stepped and not done has `open` set, and `js_release` calls its `return()`, except during the binding's teardown, which runs inside a QuickJS finalizer; proxies have a null-prototype class proto holding `[Symbol.iterator]`, a JS iterator over the foreign iterator's proxy, falling back to `Array.prototype.values` for ELEMENTS, and `toString`); and C# (`IEnumerable`/`IEnumerator`; `Protocol.Iter` marks the enumerators it hands out in a `ConditionalWeakTable`, since a `yield return` object is both and needs `GetEnumerator()` first; `Refs.Release` disposes of a marked one at its last release; `Foreign` is `IEnumerable<object?>`, and becomes an `IEnumerable<T>` parameter (`Protocol.Typed`); `Foreign.ToString()` is `ugly_to_string`; `BRIDGE_ABI` 3, and `Binding.cs` fills `Iter`/`Next`/`ToStr`); and Java (`Bridge.iter`: `Iterator`, `Iterable`, arrays (`ArrayIterator`), streams (`StreamIterator`, closed by `releaseId` at the last release); `Bridge.next(it, out, got)` fills an array, `got[0]` counting as it goes so an exception keeps the values before; `jv_next` crosses once per 256; `Foreign` is `Iterable<Object>` (natives `iter`, `next`, `toStr`), and its `toString()` is `ugly_to_string`); and Perl (decision 21, revised: arrays, and objects with a `next` method, which are their own iterators; `next` in list context, the empty list ending it, several values collapsing into an array; an array's iterator is an `Ugly::Iterator` (`helper.pm`, `{ of, at }`, walking indices); `Ugly::iter($x)` gives one over a proxy (`_iter`, else by index for ELEMENTS), an array, or an iterator itself, and its `next` on a foreign iterator is `_next`, one value per crossing; `pl_to_string` is `"$x"` through `Ugly::_str` under `G_EVAL` (overloads may die), a package's name; a proxy's `""` is `_str`, falling back to `Ugly::Proxy(<handle>)`; a proxy's `can` says yes only to existing members, since Carp asks every argument for `CARP_TRACE`; fixtures are closures in a `generator` class, and `counter` overloads `""`); pairwise checks it for every pair, and all eight languages iterate. Call options (contract §11) carry keyword arguments, a hint and a context in an `ugly_opts` (`UGLY_OPTS_INIT`; `size` first, so older callers' smaller structs work); the core borrows keyword values and refuses options for a plugin without `_opts` entries. Python takes keyword arguments; Perl and the mock take them as trailing pairs, and Perl a context; the others refuse. Bindings: native on Python proxies; a trailing marker elsewhere (`ugly.kw{}` in Lua, sorted by name; `ugly.kw({})` in JS, an `ugly.Kw` object; `Ugly::kw()` in Perl, an `Ugly::Kw` arrayref; `Ugly.kw()` in Java, `ugly.Kw`, split out on the Java side before `callKw`/`invokeKw`). Calling a proxy of a class that's INSTANTIABLE but not CALLABLE constructs it (Python caches the traits in the proxy). Hints and contexts: an `opts` marker, also passed last, beside `kw` in either order (`ugly.opts`, `Ugly::opts`, `Ugly.opts().hint(...)`); Java's hint is a per-thread "next hint" in `Bridge`, consumed by the call's overload resolution (`choose`). The core range-checks `splice` with `length` before the plugin runs, unless `describe` reports `UGLY_TRAIT_FIXED_SIZE` (then it refuses, `NOT_CAPABLE`, without asking: a lazy list's length may not return).
- `ugly_configure` (options, `lang.c`) is refused once a language is in the `langs` list, which a plugin without `term` never leaves. Plugins read options with `ugly_option` in `init` (Python, Java) or `rt_new` (Lua, Perl), or at module load (JS); `init` runs under `langs_lock`, so options have their own lock.
