# The Haskell plugin

Notes for Claude Code, loaded when working in this directory. Shared rules: `plugins/CLAUDE.md` and the root `CLAUDE.md`.

**`haskell/`** is GHC (8.8+, with shared libraries and the threaded RTS; Debian's `ghc`), language `"haskell"`. **Done** (every step of the plan; the user guide is `doc/languages/haskell.md`, the mapping contract §10's Haskell column): the author's design choices are in the guide (compiled export tables generated by Template Haskell, polymorphic functions expanded into one overload per instance, chosen at the call).

- Three libraries: `ugly_haskell.so` (the vtable, `haskell.c`, built by Meson) needs `libugly_hs.so` (`Ugly.hs` and `Ugly/*.hs` plus `glue.c`, built by ghc as package `ugly` (exposed: `Ugly`, `Ugly.Export`, `Ugly.Types`, `Ugly.Value`; hidden: `Ugly.Marshal`, `Ugly.Native`, `Ugly.Plugin`): `-this-unit-id ugly`, `.dyn_hi` interfaces, soname set, **no RTS**, so TH can load it into ghc on ghc's RTS) and `libugly_rts.so` (`rts.c`, which links the RTS: by name on 8.x, `-lHSrts_thr-ghc<ver>`, with `-flink-rts` on 9.x) beside it. ghc compiles `rts.c` because only it knows its RTS headers' location (moved in 9.4).
- `ugly_hs_start` runs `hs_init_ghc` once, with `--install-signal-handlers=no` plus the `rts` option, and `keep_cafs` (dlopen'ed libraries' foreign exports aren't roots on GHC 9); the RTS is never stopped (no `term`). Caps: `ANY_THREAD | MULTI_RUNTIME`. A runtime is a `StablePtr` to Haskell state (none yet).
- Module libraries: `.so`s built against package `ugly`, registered by `package.py` in `build/plugins/haskell/package.db` (not installed yet); Meson's recipe is `ghc_module` + `ghc_module_depends`. `uglyModule` (and `uglyModuleFrom name 'box`, for a box written by hand) declares a foreign export `ugly_hs_module_<name encoded>` (`moduleSymbol`; `haskell.c`'s `module_symbol` encodes the same) giving a `StablePtr Box`. `hs_import` (C): a per-process cache, then `dlsym(RTLD_DEFAULT)`, then `<dir>/<longest prefix>.so` over the `path` option and `UGLY_HASKELL_PATH`, `dlopen`ed `RTLD_LOCAL` and never closed. Test modules: `plugins/haskell/test/` (`Smoke.so`, `Example.so` with `Example` and `Example.Points`, and `Broken.so`, not a library).
- The vtable points straight at `Ugly.Plugin`'s foreign exports (the vtable's C signatures); `glue.c` (compiled by ghc, `-I include`) reads and writes `ugly_val` and `_Static_assert`s the status/kind/trait numbers `Ugly.Native` mirrors (bump `BRIDGE_ABI` in both `haskell.c` and `Ugly.Plugin` when the two sides change). Imports that can re-enter Haskell (`ugly_export` releases a duplicate ref synchronously) are `safe`.
- Values (`Ugly.Value`): a `Value` is a primitive or a `Box` (the value plus closures over it: type name, text, members, elements), made by `ToUgly` instances. A ref is a `StablePtr` to a box; identity is the value's `StableName` index + 1 (forced to WHNF, kept alive with the ref). Every entry point is `guarded` (any exception → `ugly_raise_native`, payload a box of the `SomeException`); values are forced inside it. `want` is strict (int → double only; a box's text for STRING). Writes are `NOT_CAPABLE`, and an immutable sequence reports `UGLY_TRAIT_FIXED_SIZE` (`hsDescribe`). `ugly_hs_live_refs` counts refs for the tests.
- Modules: `Ugly.Types` (Value, Box, Arg, Foreign, ForeignError) → `Ugly.Marshal` (refs, `guarded`, `put`, `readArg`, calling out) → `Ugly.Value` (classes, instances, `Collect`, `fromValue`) → `Ugly.Plugin` (entry points); `Ugly` is the API for Haskell code.
- Calls out are `bound` (`Ugly.Marshal`): the ctx is the OS thread's, and an unbound thread (`forkIO`) can change OS thread between two safe foreign calls, so it makes each call out through `runInBoundThread`. `raise` can't throw (an exception out of a foreign export ends the process): `withUtf8`/`peekUtf8` are lenient (U+FFFD), and an exception that can't be evaluated is raised without a payload. `STACK_CHECK` reserves a quarter of a stack of 2 MB or less. `hsSetIndex` refuses an immutable sequence before asking its length.
- Foreign values (`Ugly.Marshal`): a `Foreign` is an owned handle (an argument `AForeign` dups only if the call takes it) with a `Foreign.Concurrent` finalizer calling `ugly_release(NULL, h)` (never a C finalizer: those run inside the GC). Ops (`Ugly.call/invoke/get/index/size/members/typeOf`) go through the core on `ugly_hs_ctx()` (`glue.c`); results whose home is the current Haskell runtime are boxes: `guarded` sets a C thread-local current rt (`ugly_hs_enter`/`leave`). A failure is a `ForeignError` owning the taken `ugly_error` (freed by a weak-IORef finalizer, restored unchanged by `raise` if it escapes); a payload that's a Haskell `SomeException` is rethrown as itself (rule 7). A foreign callable taken as a function type becomes one (`Collect`: gathers args, one call; pure via `unsafePerformIO` unless `IO`). TH's `usableType` wants a callback's params `ToUgly` and result `FromUgly`. `ugly_hs_live_foreign` counts Foreigns and taken errors for the tests (`settle` in Smoke runs the GC). Test `haskell-foreign` (`foreign.c`).
- Binding: `binding.c` is `haskell.c` with `UGLY_BINDING` (no RTS start: `init` calls `setKeepCAFs()`; caps add `ATTACH`; `rt_attach`; options only `path`), compiled by ghc into `libugly_hs.so` with attach/detach for `Ugly.withUgly` (registers, `ugly_rt_attach`, nested uses counted, teardown on the attaching thread). `glue.c`'s current runtime falls back to the attached one (the program's own code). `Ugly.module_`/`Ugly.eval` (`ugly_rt_get` + import/eval). The package links `libugly` too (`extra-libraries: ugly_hs ugly`; library-dirs: plugin dir and the core's). Test `binding-haskell` (`tests/haskell/TestBinding.hs`, a ghc-built program, `-dynamic -threaded -rdynamic`; its own `uglyModule "TestBinding"` used from Python), run through `env` (Meson 0.61's `test()` takes no custom target; memcheck has `--trace-children=yes`). `tests/valgrind.supp` suppresses GHC 8.8's RTS shutdown leak (`shutdownHaskellAndExit`, a plain `print 1` has it).
- Installed (`meson install`): `package.py install` (an install script) copies the `.dyn_hi`s to `<libdir>/ugly/haskell/import` and writes `<libdir>/ugly/haskell/package.db` (then `recache`: under DESTDIR, `register` would check paths that don't exist yet). `FromUgly [a]` takes a foreign sequence too (cost 3, elements converted when the call runs).
- Example (`examples/haskell/`): music-diatonic from Hackage (`subprojects/music-diatonic.wrap`, a packagefiles `meson.build` listing its sources), export module `Music/Diatonic/Ugly.hs` → `Music.Diatonic.so` (`-w`, `-this-unit-id music-diatonic-ugly`); tests `music_from_python`, `music_from_lua` (suites `examples`, `ghc`).
- Conformance (`tests/haskell/Conformance.hs`, `uglyModule "conformance"`, built by `tests/haskell/meson.build` into `conformance.so`): counter and list are hand-written `IORef` boxes (`Members`/`Elems` read in `IO`, `memberSet`/`elemsSplice` for mutation; `fixedMembers`/`fixedElems` for immutable ones); `Point` is a record (TH: one record constructor → its fields are members, `boxRecord`) and its constructor is `INSTANTIABLE` (`constructor`, `infoNew`; `new` = call). `ConformanceError` is declared under `UglyException` (`uglyToException`/`uglyFromException`), so its payload has its `message` member (`Marshal.exceptionBox`). `finalized()` counts weak pointers a major GC found dead. `haskell.c` refuses a call when less than 1 MB of C stack is left (`STACK_CHECK`, RAISED `StackOverflow`): each re-entry costs about 17 KB. `globals` is NOT_SUPPORTED. An exception box's identity is the `StableName` of the exception *inside* its `SomeException` (`newRef`): GHC 9.10+'s `throwIO` rewraps it on every throw. Pitfall: `length` of an infinite list exhausts memory and the RTS exits the process; `-M` crashes an embedded RTS (`getTopHandlerThread`), so it's no guard. In suite `ghc` (also its pairs): CI's valgrindghc step adds `--no-suite jvm --no-suite clr` (an explicit `--suite` overrides exclusions); helgrind skips `threads-haskell`.
- Hints and want (`Ugly.Value.overloaded`): a polymorphic export (TH: every one, even with one instantiation) is a list of `Instance`s (`instantiation [type args, as Typeable shows them] f`). `infoCall` takes a `Call` (want, parsed hint) and returns `Either Refused` (`Refused` → TYPE, `NoInstance` → NOT_FOUND). The hint (`parseHint`, `normType`: `String` = `[Char]`) filters by type arguments, TypeApplications style; `want` adds the result's `wantCost` (a `ToUgly` method; `Result.matchArgs` takes the want, so an impossible result is refused before running). `haskell.c`'s `call_opts`/`invoke_opts` refuse kwargs and context, pass the hint (`ugly_hs_call`/`ugly_hs_invoke` take it; `BRIDGE_ABI` 6). Instances with variables in their heads (`Show [a]`) aren't expanded.
- Calls: `FromUgly` converts an `Arg` (decoded from C; a home handle is its box, cast back through `Typeable`) by the literal rules, with a cost; `Result` matches a function's arguments by type alone (never evaluating), then applies them (currying, `IO` runs). `overloaded` picks the cheapest instantiation, refusing ties. `invoke`: a module's function, else the exporting module's function with the receiver last (`infoMethods`). `Ugly.Value` needs `MonoLocalBinds` (else a local `call` settles `Result (a -> b)` with the overlappable instance) and `UndecidableInstances`.
- `Ugly.Export.uglyModule` (Template Haskell; CPP for TH 2.17's `TyVarBndr`): listed types get instances with methods; listed values are expanded into instantiations over the instances in scope (contexts checked recursively, unconstrained vars → `Value`), dropping silently those whose types can't cross; none left, or a higher-kinded var, is a compile error. Export modules need `-Wno-orphans`. Tests: `haskell-calls`, `haskell-exports` (with `tap.h`).
- Tests `haskell-smoke`, `haskell-values`, `haskell-calls`, `haskell-exports`, `haskell-foreign` (suites `haskell` and `ghc`). Valgrind's `--track-origins` never gets through the RTS's 1 TB reservation, so suite `ghc` is out of `valgrind` and runs under setup `valgrindghc` (the same without origins); it's out of helgrind too (the RTS's scheduler). `tests/valgrind.supp` suppresses the RTS threads' "possibly lost" blocks.
